Authentication

Two credential types, sent on every request unless noted: Authorization: Bearer <jwt> for dashboard users, or X-API-Key: <key> for agents/programmatic access. API keys carry viewer role plus scopes (brain:query, skills:invoke, …). All responses use the envelope { data, meta }; errors use { error: { code, message }, meta }.
